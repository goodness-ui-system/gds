System decisions — locked

The naming architecture we agreed on, captured so the identity and the code stay in sync.

Tagline

“The honest foundation for your interface.” Ties the honest-development methodology to the design system’s job.

Default prefix

Compiled tokens ship as --gds-color-primary — collision-safe in codebases you don’t control (the Bootstrap --bs- model).

Configurable

One build-time switch changes every token at once. Teams can shorten it or set it to empty for a bare --color-primary.

Bare authoring API

Authors always write color.primary; the prefix only appears in compiled output, so no one types “goodness” by hand.

Five logo directions

Each explores a different facet of “building something great” — architecture, blueprint, foundation, and the connected, AI-native world of new apps. One consistent palette so they read as a family.

01 · THE KEYSTONE

Keystone

The wedge stone at the crown of an arch — the single piece that locks every other stone in place and lets the structure stand for centuries. That is exactly what a design system is to a product. The gold keystone reads as “goodness” — the essential part that holds it all together.

02 · THE BLUEPRINT G

Blueprint

A confident geometric “G” drafted on a technical grid, complete with registration crosshairs and a dashed construction radius. It says spec, precision, and “designed on purpose.” The most literally on-brand for a design system — the mark itself looks like a component drawn to spec.

Cornerstone

An isometric foundation block — the first stone laid, the one every measurement is taken from. It doubles as a “building block,” the universal language of components and tokens. The gold top face catches the light like the good, solid thing you build everything else on.

04 · THE GRAPH

Node

A “G” traced by connected nodes — reading at once as a neural graph and as a system of components wired together. This is the most AI-native, new-app-world direction: it feels alive, computational, and modern, while the two gold nodes keep it warm rather than clinical.

Compass
